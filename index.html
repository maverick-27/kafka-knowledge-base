The lab cluster

Every lab uses the same three-broker cluster, defined in docker-compose.yml in this folder. It also starts a web console at http://localhost:8085 and, for module 08, a schema registry at http://localhost:8086.

cd ~/Desktop/kafka-knowledge-base
docker compose up -d

That starts six containers: three brokers, the web console, the schema registry, and a one-broker second cluster for module 10. To start only the three brokers, run docker compose up -d kafka-1 kafka-2 kafka-3. Do the labs in module order: later labs use topics that earlier labs create. To start again from nothing, run docker compose down and then up again.
